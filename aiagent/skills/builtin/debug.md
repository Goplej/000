# Отладка ошибки

## 1. Воспроизвести
1. Получи точный текст ошибки (traceback, лог, шаги). Без воспроизведения не менять код.
2. Запусти минимальный сценарий: `run_code` или `run_shell` с той же командой.
3. Если ошибка плавающая — добавь логирование и повтори 3–5 раз, ищи закономерность.

## 2. Локализовать
1. `grep_search` по имени функции/переменной из traceback — найди определение.
2. `read_file` вокруг места падения (обрати внимание на номера строк из traceback).
3. Проверь входные данные: типы и значения (`run_code` с `print(type(x), repr(x))`).
4. Читай traceback снизу вверх: самый нижний кадр в *твоём* коде — источник.

## 3. Исправить
- Правь минимально: одна причина — одно изменение. Не переписывай соседний код «заодно».
- Используй `edit_file` с точным `old_text`; после правки сразу прочитай изменённый участок.
- Если причина в неверном предположении об API — сверься с документацией (`fetch_url`) или подсказкой провайдера.

## 4. Проверить и защитить
1. Повтори воспроизводящий сценарий — ошибка должна исчезнуть.
2. Прогони существующие тесты: `pytest -q` (или аналог).
3. Добавь регрессионный тест именно на этот случай.
4. Расскажи: что было, почему сломалось, что изменено, чем проверено.
