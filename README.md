# The Director

**Режиссируемый психологический хоррор для Minecraft 1.20.1 (Forge 47.2.0).**
Внутри мода нет ни ИИ, ни LLM, ни единого сетевого запроса. Всё, что происходит, — заранее
написанная драматургия, машина состояний и ванильные материалы.

- **modid:** `thedirector`
- **Версия:** 1.0.1
- **Minecraft:** 1.20.1 · **Forge:** 47.2.0+ · **Java:** 17 · **Gradle:** 8.4 · **Mappings:** official (Mojang)
- **Готовый JAR:** `build/libs/thedirector-1.0.1.jar` (в git также лежит копия в `ci/thedirector-1.0.1.jar`)

---

## 1. Что это за мод

Это не мод про монстра. Это мод про **систему**, которая:

1. Наблюдает за игроком и хранит его память (NBT на игроке).
2. Создаёт иллюзию безопасности: длинная тишина — потом удар.
3. Ломает привычный мир микрособытиями: блок, которого не было; вещи, переложенные в сундуке;
   строка в чате, которую игрок не писал.
4. Управляет атмосферой: мерцание огня, туман без причины, приглушённая музыка, виньетка.
5. Ведёт игрока по драматургической дуге из 4 актов.
6. Забирает его в измерение **Сон** — копию собственного дома, из которой убрали жизнь.
7. **Никогда ничего не объясняет.**

Игрок достраивает ужас сам. Мод даёт только намёки.

## 2. Установка

1. Установите **Minecraft 1.20.1** и **Forge 47.2.0** (или новее в ветке 47.x).
2. Соберите мод (или возьмите готовый JAR):
   ```
   ./gradlew build
   ```
   Результат: `build/libs/thedirector-1.0.1.jar`.
   > В `build/libs` дополнительно появится только reobfuscated JAR (`distJar` кладёт его
   > под именем `thedirector-1.0.1.jar`). Именно он идёт в игру: в 1.20.1 моды обязаны быть
   > переобфусцированы в SRG для продакшена.
3. Положите JAR в папку `.minecraft/mods/`.
4. Запустите игру с профилем Forge 1.20.1.

Сервер: JAR ставится и в `mods/` сервера. Мод работает на **обеих сторонах**: сервер —
единственный, кто принимает решения; клиент только показывает эффекты. Если у клиента мода нет,
сервер продолжит работать, но игрок не увидит визуальных эффектов.

### 2.1. Как понять, что мод работает

Хоррор незаметен по замыслу: мод не объясняет себя игроку. Поэтому проверка — отдельными шагами,
от очевидного к точному.

**Уровень 1 — мод вообще загрузился**

| Признак | Где смотреть |
|---|---|
| Мод в списке | главное меню → **Mods** → *The Director* |
| Строка загрузки в логе | `[The Director] Загружается. Он уже смотрит.` — в `logs/latest.log` |
| Появился конфиг | `config/thedirector-common.toml` создаётся сам при первом запуске |

Если мод не в списке — он не загрузился (не та версия Forge/Java, или JAR не в `mods/`).
Никаких табличек, команд в чате и объяснений при входе в мир не будет: это нормальное поведение мода.

**Уровень 2 — режиссёр действительно считает**

```
/thedirector status
```

Доступна всем игрокам. Печатает акт, день, `безопасность / страх`, определён ли дом по ночёвкам,
сколько света поставлено, сколько событий сработало, сколько идёт молчание и сколько осталось до
следующего события. Если числа меняются со временем (особенно `Молчание` и `Пауза до следующего`) —
машина состояний работает.

```
/thedirector events
```

Список всех 13 событий с пометками: `✔` доступно сейчас, `~` нужен подходящий контекст
(например, сундук рядом), `✘` закрыто текущим актом.

**Уровень 3 — события реально выполняются**

```
/thedirector event whisper      # шёпот за спиной
/thedirector event torch_extinguish
/thedirector event chat_message
/thedirector event fov_shrink
/thedirector act 4              # перейти в акт 4, чтобы открылись жёсткие события
/thedirector event fake_crash   # экран краха на 7 секунд
```

Требует прав оператора (в одиночной игре — включённые читы). Сервер ответит, как событие
изменило память: `Страх: N, безопасность: M, акт: K`.

**Уровень 4 — измерение Сна**

```
/thedirector dream      # принудительный сон, без ожидания шанса
/thedirector wake       # выход
```

Через несколько секунд игрок оказывается внутри копии своего дома: мобы отсутствуют, солнце стоит
на месте, кровать не работает, разбитый блок возвращается через секунду, шаги звучат с эхом.

**Уровень 5 — полный журнал действий режиссёра**

```toml
# config/thedirector-common.toml
[meta]
    enableMetaEvents = true
```

Мод начнёт писать `logs/thedirector_meta.log` — там по секундам видно каждое решение:
`player=… act=2 day=9 safety=17 dread=4 event=whisper`. Это единственное место, где режиссёр
говорит прямо; в игре он этого не делает никогда.

**Уровень 6 — самотест на выделенном сервере** (для автора/владельца сервера, 18 проверок):

```bash
mkdir -p run && echo "eula=true" > run/eula.txt
THEDIRECTOR_SELFTEST=1 ./gradlew runServer
```

В логе появятся строки `[OK]`/`[FAIL]` и итог `SELFTEST_DONE OK`, после чего сервер выключится сам.

**Чего не увидит игрок:** ни одного сообщения «мод запустил событие», ни одной подсказки,
ни единого объяснения. Если что-то произошло и непонятно почему — это и есть работа режиссёра.

## 3. Конфиг

`config/thedirector-common.toml` создаётся при первом запуске:

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `meta.enableMetaEvents` | `false` | Мета-слой: журнал `logs/thedirector_meta.log` (и клиентский `thedirector_meta_client.log`) |
| `meta.enableMetaScreenshots` | `false` | Скриншоты в момент крупных событий |
| `meta.logEvents` | `false` | Писать каждое событие в общий лог сервера |
| `dream.enableDreamDimension` | `true` | Включает измерение Сна |
| `dream.dreamChance` | `0.3` | Базовый шанс сна (итоговый = `dreamChance + dreadLevel / 200`) |
| `dream.dreamDurationMinutes` | `10` | Через сколько игровых минут сон отпускает игрока |
| `director.eventFrequency` | `100` | Частота опроса режиссёра в тиках (5 секунд) |
| `director.enableTorchFlicker` | `true` | Мерцание огня рядом с игроком |
| `director.actDayScale` | `1` | Множитель скорости актов (2 = акты идут вдвое быстрее, удобно для тестов) |

## 4. Драматургия: четыре акта

| Акт | Дни (по умолчанию) | Что происходит |
|---|---|---|
| **1. Смутное беспокойство** | 1–5 | Только атмосфера и микрособытия. Ничего прямого, всё списывается на баги |
| **2. Что-то не так** | 5–15 | Шёпот, обрывки в чате, следы. Тишина чередуется с событиями |
| **3. Вторжение** | 15–25 | Сущность входит в личное пространство: шаги на крыше, свет гаснет, вещи перекладываются |
| **4. Точка невозврата** | 25+ | Мир не безопасен нигде: даже днём, даже в деревне. Ложный краш. События постоянны |

Акт определяется по `daysInWorld` и не откатывается назад.

### Правила режиссёра

```
safetyLevel > 15 && dreadLevel < 5   →  можно запускать крупное событие
dreadLevel  > 15                     →  тишина: мод не добивает, страху дают улечься
daysInWorld > 25                     →  акт 4: события идут постоянно
```

- `safetyLevel` растёт каждые 45 секунд тишины; для страха тишина — приманка.
- После каждого события режиссёр замолкает: 10–24 с в акте 1 и всего 1.5–5 с в акте 4.

## 5. Реализованные события (13)

| Событие | Акт | Что делает |
|---|---|---|
| `whisper` | 1+ | Звук шёпота ровно там, куда игрок не смотрит. В акте 3+ — подтверждающее дыхание через 2 секунды |
| `fake_block` | 1+ | Один блок, идеально вписанный в окружение. Исчезает через 20–80 с (в акте 4 остаётся) |
| `window_title` | 1+ | Подмена заголовка окна на искажённое/пустое название |
| `chat_message` | 2+ | Обрывок фразы в чате; в акте 3+ — **от имени самого игрока** |
| `torch_extinguish` | 2+ | Гаснут факелы и фонари; свет возвращается через 1–4 с |
| `moved_chest` | 2+ | Два предмета в сундуке меняются местами (в акте 3+ предмет может "уехать" в память режиссёра) |
| `fov_shrink` | 3+ | Сужение FOV, лёгкая тряска камеры, виньетка |
| `roof_steps` | 3+ | 3–10 шагов по крыше дома — последний звучит внутри, над головой |
| `lost_return` | 3+ | Возврат потерянной вещи: чужое имя, странное место, иногда метка ключа от сна |
| `lights_out` | 3+ | Все источники света в радиусе 24 блоков гаснут (в акте 4 часть не загорается) |
| `daylight_thunder` | 4 | Гроза при ясном небе — даже днём нет безопасного времени |
| `watcher` | 4 | Композиция: шёпот в упор, шаги, тьма, сужение зрения, сообщение "от игрока", вторая волна через 6 с |
| `fake_crash` | 4 | Экран краша с правдоподобным стеком **ванильных** классов на 7 секунд. Затем мир возвращается |

Все события — отдельные классы с методом `execute(Player, Level, PlayerMemory)` в пакете
`com.thedirector.director.event`.

## 6. Память игрока (NBT capability)

`com.thedirector.memory.PlayerMemory` хранится как capability на игроке и сериализуется в NBT,
переживая перезаход и смерть:

`safetyLevel`, `dreadLevel`, `currentAct`, `lastSeenPos`, `baseLocation` (вычисляется по статистике
ночёвок: три ночи в одном месте), `lightUsage`, `undergroundTime`, `encounterCount`, `lostItems`,
`daysInWorld`, `eventsHistory`, `inventorySnapshot`, `dreamVisits`, `dreamTicks`, `returnAnchor`.

---

## 7. Измерение "Сон"

Регистрация — датапаком: `data/thedirector/dimension_type/dream_type.json` и `data/thedirector/dimension/dream.json`
(генератор `minecraft:flat` в биоме `the_void`, фиксированное время 6000, без мобов).

- **Вход:** игрок ложится спать и просыпается… не там. Шанс = `dreamChance + dreadLevel/200`, не чаще
  одного раза в игровой день.
- **Мир сна:** копия последних **100×100** блоков вокруг базы игрока (14 блоков над поверхностью,
  4 под ней), скопированная порциями, чтобы не ронять TPS. Внутри:
  - нет мобов (спавн отменяется);
  - вода не течёт, лава не жжёт, утонуть и упасть в пустоту нельзя;
  - солнце стоит на месте, время не идёт;
  - кровать не работает;
  - **блоки ломаются, но возвращаются через 1 секунду**;
  - музыка приглушена, слышны только собственные шаги с эхом.
- **Выход:**
  1. Использовать свою изменённую вещь — предмет с меткой `thedirector:dream_key`
     (клавиша использования по предмету в руке);
  2. "Умереть" — смерть во сне отменяется, игрок просыпается там, где лёг, потеряв одну вещь;
  3. Через 10 игровых минут сон отпускает сам.

## 8. Система порчи предметов

При входе в сон (`com.thedirector.corruption.ItemCorruptionSystem`):

- **Ванильные предметы не меняются.** Обрабатываются только не-ванильные (namespace ≠ `minecraft`).
  Если в инвентаре нет ни одного модового предмета, система аккуратно портит один-два ванильных —
  иначе механика была бы невидимой в чистом мире.
- Применяются четыре операции: имя в NBT меняется на жуткое; предмет дублируется в другой слот;
  предмет заменяется на **двойника** (`thedirector:twin_item`, визуально та же вещь, но другой ID);
  предмет начинает работать наоборот (использование даёт тошноту, голод и урон).
- **Предметы никогда не исчезают полностью.** Подменённая вещь уходит в память режиссёра и
  возвращается позже в чужом сундуке или в странном месте (`lost_return`).

## 10. Ресурсы

Все ресурсы либо сгенерированы программно, либо синтезированы — сторонних ассетов в моде нет.

| Ресурс | Как получен |
|---|---|
| 12 звуков (шёпот, дыхание, шаги, гул сна, помехи, краш, скрежет, гром…) | `tools/generate_sounds.py` — синтез на numpy (шум + резонансные фильтры + огибающие), запись в Ogg Vorbis через libsndfile |
| Иконка мода `icon.png` | процедурная отрисовка (кольцо, зрачок-щель, красный шов) |
| Текстура предмета-двойника | процедурная отрисовка 16×16 |
| Языковые файлы | `lang/en_us.json`, `lang/ru_ru.json` |

Перегенерировать звуки:

```bash
pip install soundfile numpy
python3 tools/generate_sounds.py
```

## 11. Самопроверка

В моде есть встроенный самотест — он запускается только при переменной окружения
`THEDIRECTOR_SELFTEST=1` и проверяет на **настоящем выделенном сервере**, что измерение сна
зарегистрировано датапаком, тип измерения корректен (кровать не работает, время стоит),
реестр событий заполнен, конфиг читается, capability и NBT памяти работают, а планировщик
отложенных задач действительно выполняет задачи. Затем сервер сам выключается.

```bash
mkdir -p run && echo "eula=true" > run/eula.txt
THEDIRECTOR_SELFTEST=1 ./gradlew runServer
```

Отчёт печатается в лог строками `[OK]` / `[FAIL]` и завершается строкой `SELFTEST_DONE OK`.

## 12. Структура проекта

```
build.gradle, settings.gradle, gradle.properties, gradlew, gradle/wrapper/   — стандартный Forge MDK на Gradle 8.4
src/main/java/com/thedirector/
  TheDirector.java            — точка входа
  Config.java, ModItems.java, ModSounds.java
  memory/                     — PlayerMemory (NBT), провайдер capability, события жизненного цикла
  director/                   — Director (акты, решения), EventDirector (выбор), Act, DirectorEvent
    event/                    — 13 событий + support/Search
  dream/                      — DreamDimension, DreamReplicator (копия мира), DreamEvents (правила сна)
  corruption/                 — ItemCorruptionSystem, CorruptionEvents
  network/                    — NetworkHandler + packet/ (9 пакетов)
  client/                     — ClientEffects, AtmosphereManager, ClientMetaHandler (Dist.CLIENT)
  util/                       — ScheduledTasks, Texts, MetaLayer, CorruptionTags, TickHandler
src/main/resources/
  META-INF/mods.toml, pack.mcmeta, icon.png
  assets/thedirector/         — sounds.json + 12 синтезированных .ogg, lang/en_us.json, lang/ru_ru.json, models/item, textures/item
  data/thedirector/dimension_type/dream_type.json
  data/thedirector/dimension/dream.json
```

Мод идейно несовместим с «рассказыванием о себе»: ни один текст в игре не объясняет, что произошло.
Единственное место, где режиссёр говорит прямо, — журнал мета-слоя, который по умолчанию выключен.
